# Backyard Airport — เดโมระบบจองที่จอดรถ

ลูกค้าจองที่จอดและรถรับส่งสุวรรณภูมิใน LINE จ่ายผ่าน PromptPay ระบบตรวจสลิปให้เอง แอดมินกับคนขับดูงานผ่านเว็บ

| หน้า | ใช้โดย | ทำอะไร |
| --- | --- | --- |
| `/liff/book` | ลูกค้า (เปิดจากเมนู LINE) | เลือกวัน ใส่ทะเบียน เลือกรถรับส่ง เห็นที่ว่างและราคาทันที |
| `/liff/pay/[id]` | ลูกค้า | QR PromptPay ตามยอด นับเวลากันที่ 15 นาที ส่งสลิป |
| `/liff/my` | ลูกค้า | การจองของฉัน |
| `/admin` | แอดมิน (รหัสผ่าน) | ที่ว่าง 30 วัน เที่ยวรถ 3 วัน คิวทะเบียนไม้กั้น สลิปที่ตรวจไม่ผ่าน |
| `/driver?key=…` | คนขับ | งานวันนี้และพรุ่งนี้แยกตามรถ ปุ่มโทรหาลูกค้า |
| `/api/line/webhook` | LINE | ต้อนรับเพื่อนใหม่ ตอบราคา ตอบเรื่องแอดมิน (ใช้ข้อความตอบกลับ ไม่เสียโควตา) |

## ติดตั้ง (ราว 30 นาที)

### 1. Supabase
1. สร้างโปรเจกต์ใหม่ (region Singapore)
2. SQL Editor: รัน `supabase/migrations/0001_init.sql` แล้วตามด้วย `0002_storage_and_jobs.sql`
   - ถ้าจะให้ระบบปล่อยที่ที่ไม่จ่ายเงินอัตโนมัติ ให้เปิด extension `pg_cron` ก่อนรัน 0002
3. ถ้าอยากให้หน้าแอดมินมีข้อมูลตัวอย่าง: รัน `supabase/seed_demo.sql`
4. Project Settings › API: คัดลอก Project URL กับ `service_role` key

### 2. LINE
1. สร้าง LINE Official Account (แพ็กเกจฟรี) แล้วเปิดใช้ Messaging API
2. ใน LINE Developers ช่อง Messaging API: คัดลอก Channel secret และออก Channel access token
3. สร้างช่อง LINE Login ใน Provider เดียวกัน แล้วเพิ่ม LIFF app:
   - Size: Full · Endpoint URL: `https://<โดเมน Vercel>/liff` · Scope: `openid`, `profile`
   - คัดลอก LIFF ID และ Channel ID ของช่อง LINE Login
4. หลัง deploy แล้ว: ตั้ง Webhook URL เป็น `https://<โดเมน>/api/line/webhook` และเปิด Use webhook
5. ใน LINE OA Manager › ตั้งค่าการตอบกลับ: เปิดทั้ง Chat และ Webhook (แอดมินยังแชทเองได้)

### 3. Vercel
1. Push โฟลเดอร์นี้ขึ้น GitHub แล้ว Import ใน Vercel
2. ใส่ Environment Variables ตาม `.env.example`
3. Deploy

### 4. เมนู LINE
```bash
cp .env.example .env.local   # ใส่ค่าจริง
npm install
npm run richmenu             # สร้างเมนู 5 ปุ่ม อัปโหลดรูป ตั้งเป็นเมนูหลัก
```

## เดโม 5 นาที
1. ให้ลูกค้าสแกน QR เพิ่มเพื่อน LINE OA จะได้การ์ดต้อนรับ และเห็นเมนู
2. กด "จองที่จอดรถ" แล้วกรอกฟอร์ม จะเห็นว่าที่ว่างและราคาเปลี่ยนทันที
3. จ่ายผ่าน QR (เดโมใช้ `SLIP_PROVIDER=mock` ส่งรูปอะไรก็ผ่าน ถ้าจะตรวจจริงให้เปลี่ยนเป็น `easyslip` หรือ `slipok` แล้วโอนจริง 1 บาท โดยตั้งราคาเดโมให้ต่ำ)
4. ได้ข้อความยืนยันในแชท
5. เปิด `/admin` ให้ดูว่าที่ว่างลดลง มีทะเบียนรอเพิ่มเข้าไม้กั้น และเที่ยวรถถูกจัดให้รถแล้ว
6. เปิด `/driver?key=…` บนมือถืออีกเครื่องเป็นหน้าคนขับ

## ทดลองในเครื่องโดยไม่ต้องมี LINE
ตั้ง `DEMO_MODE=true` แล้วไม่ต้องใส่ `NEXT_PUBLIC_LIFF_ID` จากนั้น `npm run dev` แล้วเปิด http://localhost:3000
ระบบจะใช้ผู้ใช้สมมติชื่อ `demo-user` (ห้ามเปิด DEMO_MODE ตอนใช้งานจริง)

## สิ่งที่ยังไม่มีในเดโม (ตามแผนเฟส)
- ส่งทะเบียนเข้าไม้กั้นอัตโนมัติ (ตอนนี้แอดมินกด "ทำแล้ว" ตามคิว)
- ติดตามเที่ยวบินอัตโนมัติ (ตอนนี้ลูกค้ากรอกเวลาเครื่องลงเอง)
- การเลื่อนวันจากหน้าลูกค้า (มีฟังก์ชันในฐานข้อมูลแล้ว: `reschedule_booking`)
- ตรวจบัญชีผู้รับในสลิปกับ EasySlip (ต้องลงทะเบียนบัญชีรับเงินในระบบ EasySlip ก่อน)

## ทดสอบแล้ว
- `npm run build` ผ่าน (Next.js 15)
- ฐานข้อมูล: `tests/test_0001.sql` ผ่าน 12 กรณี
- รันทั้งระบบในเครื่องกับ Postgres 16: จอง → QR 600 บาท → ส่งสลิป → ยืนยัน → จัดรถคันที่ 1 ทั้งขาไปและขากลับ (ขากลับรับหลังเครื่องลง 60 นาทีสำหรับไฟลต์ต่างประเทศ) → หน้าแอดมินและหน้าคนขับแสดงงาน
- QR PromptPay: ข้อมูลตรงกับไลบรารี `promptpay-qr` และ checksum ถูกต้อง
